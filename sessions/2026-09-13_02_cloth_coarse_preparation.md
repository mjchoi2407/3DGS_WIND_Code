# 저해상도 천 굽힘 비교 실행 연결

## 현재 상태

- 사용자 승인: 별도10초 `visual_v1`에서 기하 flag만 중단 조건에서 제외하고 원래 수치·flag·경고 횟수를 기록한다. 나머지 검산과 strict 모드는 유지한다. 시각 확인 전용·학습 부적격, 9개 씬 준비만 완료. GPU 마스크7조건 검증 통과. 기존 결과 변경 없음.

- 사용자 요청의 별도10초 비교 준비: `run_cloth_coarse_10s.sh`, 3메시×3굽힘 조건 각각600프레임. 기존4초 실행 보존, 프레임별 계측·2초 저장·Ctrl+C 정책 유지. 원본600프레임 바람·9개 plan 및 ready0 검증 완료, 본 계산 미실행.

- 사용자 정정: 기본 `gpu_v6`는 매1프레임 GPU 완료 확인·실패 상태 조회 후 시간 출력. 물리 상태 저장은2초 유지, 프레임 로그는 즉시 기록. 동기화 비용이 추가되므로 두 컴퓨터 모두 같은 버전끼리 비교한다. v5 이하 동결본은 보존한다.

- 터미널 요약 요청 반영: 현행 기본 `gpu_v5`. 확정 보고서의 새 구간만 프레임 범위·계산/검산·저장·전체 시간으로 표시한다. 기본2초 저장 경계를 유지하며 추가 GPU 동기화 없음. 실제 저장 보고서2구간 출력/중복 방지와 Ctrl+C 회귀3개 통과. 기존 실행/결과는 보존했다.

- Ctrl+C 요청 반영: 기본 `gpu_v4`에서 controller가 소유 worker 종료·2초 timeout 후 kill·다음 씬 중단을 처리한다. 미저장 구간 폐기, 확정 결과 보존, `interrupted` 자동 재개 금지. 중단 검사3개 통과. 조회 시 메인컴에는 천 실행이 없었고 cuDSS probe는 보존했다. 기존 동결 실행은 수정하지 않았다.

- 구간 시간 요청 반영: 현행 기본 출력은 `20260913_cloth_coarse_4s_gpu_v3`. 기존v2는 보존한다. 저장 구간별 계산·검산/경계 확인/전송·저장·해시 시간과 정상 처리 수, 장치·재개 초기화 조건을 기록한다. 기존 저장 경계 외 GPU 동기화는 추가하지 않았다. 짧은1프레임·재개1프레임의 구간 시간/합계/기록 보존 검증 통과. 전체4초 성능 측정은 사용자 실행 대기다.

- 확인 기준일: 2026-09-13. 현행 비교를 최적화 GPU 생성·독립 검산으로 갱신했다. 새4초 본 실행은 준비만 완료했다.
- `teacher_cloth_gpu_sweep`은 기존 물성·메시·dt·Gate를 유지하고 매 프레임 GPU 내부 검산, 기본2초 무압축 저장을 연결한다. GPU 실패 전파 후 정상 전체 프레임만 확정하고 후보 실패 구간은 별도 저장한다.
- 저장 raw hi/lo 경계로 재개한다. `ResidentAudit`의 기준 궤적 대조 기본값은 유지하고 새 생성용 GPU 입력만 추가했다.
- 실제9조건 첫1프레임과 직사각형 저장 재개1프레임, 검산 회귀8개·CPU18개 통과. [실행 근거](../../experiments/R1_teacher_velocity_reset/timestep_search/cloth_coarse/gpu_validation.json).
- 사용자 보고 `geometry_bound_unresolved`는 현행 투영 충분조건 실패다. 실제 교차 여부는 실패 원본 부재로 미확정이며 검사 기준을 완화하지 않았다.
- 실행기가 물성 설정을 무시하고 기본 `P3Shell`을 생성하던 부분을 보완했다. 기존 실행의 물성은 기본값과 같았으므로 과거 결과의 적용값은 바뀌지 않는다.
- 공통 모델 생성기로 E·ν·h·면밀도와 직사각형 해상도를 전달하고 실제 적용 물성을 보고서에 남긴다. 기존plan의 직사각형 기본32 호환을 유지한다.
- 굽힘만 비례 변경하는 세 조건의 동결·순차 실행·중단·실패 분리·중복 lock을 연결했다.
- 새 저해상도 plan에 맞는 저장 결과 재생과 삼각 깃발 선택을 추가했다.
- 이전 하이브리드 준비의 CPU17개 검사 통과: 세 메시 실제 rest 강성의 면내 유지·법선 성분 비율, 물성 전달, 실행기 회귀, 해상도 변경 prefix 거부, 재생 기하.
- 실제9개 모델 준비 검증·hash 확인 완료. 짧은 GPU 적분은 통과했지만 새 OpenGL 실행·4초 움직임 개선은 미검증이다.
