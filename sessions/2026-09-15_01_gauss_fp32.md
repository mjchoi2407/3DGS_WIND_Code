# Gauss FP32 hi/lo 비교

## 현재 상태

- 확인 기준: 2026-09-15. 행·열 평형화 단독과 FP64 참 잔차+FP32 선형 보정의 후속 비교를 완료했다. 혼합 후보는 두 국소 프레임의 원래 FP64 검산을 통과했으며 기본 채택/장기 검증은 미완료다. [후속 결과](../../experiments/R1_teacher_velocity_reset/timestep_search/cloth_coarse/gauss_scaling_trial.md).
- 선행 FP32 비교는 별도 동결 runtime에서 GPU 힘/HVP·GMRES·희소 풀이·stage/state를 FP32 hi/lo로 전환한 개발 경로다.
- 원래 FP64 stage 검산과 실제 한 프레임 비교를 연결했다. 기본 FP64 hi/lo·물성·dt·학습 Gate는 변경하지 않았다.
- 선행 전 구간 FP32는 같은 허용오차의 FP64 대조까지 완료했지만 두 구간 공통의 유효한 정확도 설정은 확보하지 못했다. 후속 혼합 후보의 정확도 회복과 구분한다.
- 약한 외력 아래의 무반응을 가속으로 세지 않으며, 반복 풀이 실패와 검산 기준 초과를 구분한다. FP32 전 구간 채택과 장기 검증은 미완료다.
- 입력·수치·실패 분모·허용오차와 후속 판단은 [실험 보고서](../../experiments/R1_teacher_velocity_reset/timestep_search/cloth_coarse/gauss_fp32_trial.md)가 소유한다.
- [구현 계약](../docs/gpu_gauss_solver.md#fp32-hilo-개발-비교-경로), 준비/풀이/검산/분석 스크립트의 Python 구문 검사와 실제 GPU 비교를 수행했다.
- R1에는 개발 후보와 공식 검산/teacher 채택의 경계를 반영했다. 커밋·푸시 없음.

## 행·열 평형화와 FP64 보정 후속

- 별도 FP32 보조 행렬의 R P C/RHS/해 역변환과 GPU 상주 혼합 Gauss 후보를 구현했다. 원래 FP64 잔차를 계산하며 FP32 보정 RHS 정규화와 최대4회 재보정을 적용한다.
- GPU 작은 fixture의 FP64 대조·CPU longdouble 독립 검산·host 조회 금지·재시작·실패 보존 검증을 통과했다. 기본 경로는 유지한다.
- 스케일링 단독은 정체를 해결하지 못했다. RHS 정규화가 포함된 혼합 후보는 원래 기준을 유지하며 두 국소 프레임을 완료했다. 보정 비용 포함 풀이 이득은 구간에 따라 작았고, 전체 생성기/다른 메시/장기 검증은 남아 있다.
- 상세 수치와 채택 한계는 [후속 보고서](../../experiments/R1_teacher_velocity_reset/timestep_search/cloth_coarse/gauss_scaling_trial.md)를 따른다.
