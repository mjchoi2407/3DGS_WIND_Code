# Small Steps XPBD 소규모 후보

## 현재 상태

- 2026-09-30 사용자 승인 범위인 XPBD 후보 구현·작은 GPU 테스트·결과 정리를 완료했다. 기존 teacher 최종 교체나 학습 승인이 아니다.
- [조건·식별·결과](../../experiments/R1_teacher_velocity_reset/self_contact/xpbd_pilot.md#현재-상태): 메인 GTX1080Ti, 중력1초/wind2초,16/32 후16 실패·민감도를 근거로64만 추가.
- [실행 결과·시간 경계·실패 분모](../../experiments/R1_teacher_velocity_reset/self_contact/xpbd_pilot.md#실행-결과): 고유6조건 중5완주·1실패. wind32/64의2초 루프가약2.13/4.19초.
- wind16의69번째 저장 상태 자기교차를 실패로 보존했다. 승인68+실패1이며 뒤51프레임을 실행하지 않았다.
- [모델·접촉 범위](../../experiments/R1_teacher_velocity_reset/self_contact/xpbd_pilot.md#조건과-구현-범위): P1 StVK block/dihedral·FP32·lumped mass·이산 VF/EE. 기존 IPC CCD·정밀 힘/에너지 검산을 승계하지 않는다.
- [움직임·시간 민감도](../../experiments/R1_teacher_velocity_reset/self_contact/xpbd_pilot.md#움직임과-민감도): 큰 움직임은 유지되나 잔진동 해결 근거 없음. wind32/64 위치 RMS2.93cm·속도 벡터 차이44.84%.
- CPU 독립 기준·작은 CUDA·접촉·실패 보존 검사13개 통과. 실행 동결 물리 소스와 현재 소스 동일, 입력/결과 manifest 검증.
- [뷰어·원본·GIF](../../experiments/R1_teacher_velocity_reset/self_contact/xpbd_pilot.md#재생과-원본): 기존 P3/32/64 표시, 실제1프레임 렌더 성공. 자동 이미지 열람 오류로 시각 품질은 미판정.
- 기록 후 실행기는 실패 프레임의 저장 수와 승인 수를 분리했다. 원본 숫자는 보존하고 [요약 근거](../../experiments/R1_teacher_velocity_reset/self_contact/xpbd_pilot_results.json)의 `accepted_frames`로 정정 해석한다.
- 다음은 사용자 시각 확인 후 접촉 견고성·시간 민감도 개선 여부 결정.128/큰 메시/10초/학습은 실행하지 않았다.
- R1 제한 CG 경계를 확인했다. 새 모델은 채택 전 후보여서 canonical/R/TeX/PDF 변경 없음.
- 기존 dirty·모든 원본·서브 실행 보존. code·experiments 미커밋, commit/push/fetch 없음. 논문 웹 열람만 했고 외부 코드·패키지 다운로드 없음.
