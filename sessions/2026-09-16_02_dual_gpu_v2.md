# dual_gpu v2 실행 준비

## 현재 상태

- 확인일: 2026-09-16. 구현/CPU 준비 검증 완료, GPU 실행은 사용자 담당으로 대기.
- [구현·재현 안내](../docs/dual_gpu_v2.md). v1 결과와 생산 정책 보존.
- 정확 일치 필수 채택 조건 제거, 회귀 예산 부재와 검산/성능 실패를 분리. 승인 profile을 임의 발행하지 않음.
- 실제 바람 checkpoint W1과 forcing index/절대 시간을 복원. 균형 반복·telemetry·기존 보정 FP32 eager/Graph 측정 준비.
- 검증: CPU 테스트10개(캐시/판정9, 전체 일정·집계 fixture1), 실제 C0/W1 prepare-only ZIP 생성, W1 상태/바람/시간 연결, 보정 source Python 컴파일·shell 문법 확인. fixture는 GPU 측정이 아님.
- GPU Graph/성능/교차 장치 수치와 실제 cache hit는 미검증. 다음 작업은 사용자 두 PC 실행 후 취합.
- R1의 solver/정확도 계약과 teacher Gate는 바뀌지 않아 TeX 수정/PDF 빌드 대상 없음.
- commit/push 없음. 기존 사용자 변경 보존.
