# GPU 상주 검산

## 현재 상태

- 확인일:2026-09-13. 완료된 hi/lo 궤적을 다시 계산하는 GPU 검산기 구현·검증 완료.
- 힘·에너지·질량 풀이·위치·기하 상한·기준 궤적 대조를 GPU에서 수행한다. CPU는 초기 준비·입출력·요약 기록을 담당한다.
- 기존 검사 항목·물리 한도를 유지하고 불필요한 강성 행렬 초기화를 제거했다. 기존 검산기와 적분기는 보존했다.
- 새 graph는 자식 cuDSS graph까지 host 전송·callback 부재를 검사한다. 단계별 CPU 수치 조회는 없다.
- 실제7081점640구간의 기존 검산 대조 및 회귀7개 통과. 재시뮬레이션은 수행하지 않았다.
- GPU hi/lo와 CPU longdouble·LU 차이로 bitwise 일치를 주장하지 않는다. 기하 상한·실패 판정과 수치 대조를 별도로 검증했다.
- 압축/무압축 원시 기록은 메모리가 제한된 청크로 읽는다. 기본 검산64구간은 원래2초 저장 간격과 별개다.
- [API](../docs/usage.md#저장-궤적의-gpu-상주-검산), [조건·결과·해시](../../experiments/R1_teacher_velocity_reset/timestep_search/gpu_resident/audit_validation/README.md).
- 후속:사용자 환경의 실행 결과 확인 및 다른 메시·긴 구간 검증. 학습 발행·R1 Gate·장기 기본값 판정은 변경하지 않았다.
- Code 관련 worktree 변경만 수행. 커밋·푸시 없음.
