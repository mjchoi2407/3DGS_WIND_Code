## 기록 찾기와 작성

맥락이 충분하면 다시 읽지 않는다. 부족하면 해당 주제의 note 현재 상태에서 상세 절 링크를 따라 필요한 정보만 확인한다. [필수 기록·링크·갱신 규칙](../../AGENTS.md#간결한-작업-기록)을 적용하며, 기록에 적힌 다음 작업은 새 실행의 포괄적 승인이 아니다.
